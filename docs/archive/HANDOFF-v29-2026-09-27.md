## 2. 技术

- Vite 8 + TypeScript + d3-force，纯静态，`base: './'`。
- 路由用 hash：`#/节点id`、`#/resume`、`#/contact`。
- 常用命令：
  - `npm install`
  - `npm run dev`：本地开发
  - `npm run build`：生成 `dist/`，给 GitHub Pages 用
  - `npm run build:file`：生成单文件 `preview.html`
- 文件分工：
  - `src/content.ts`：**所有文字内容都在这里**，改内容只需要动这个文件。
  - `src/map.ts`：地图、布局、镜头。
  - `src/panel.ts`：右侧面板。
  - `src/main.ts`：顶栏、介绍条、路由。
  - `src/mobile.ts`：手机版。
  - `src/shapes.ts`：形状。
  - `src/style.css`：样式和颜色。

### 页面布局

- **顶栏**：
  - 左边 "wenyi zhu ✳"，不加粗。
  - 右边 "中文 · Resume ↗ · Let's talk ↗"。
- **介绍条**：顶栏下面的横条，一句话 + 4 个关键数字。
  - 首次进入时展开，开始浏览后自动收起。
  - 点名字旁的 ✳ 可以打开或收起。
- **右侧面板**：垂直居中，有图片时图片在上。
- **底部说明栏**：图例和"PROTOTYPE · PLACEHOLDER COPY"，上线前删掉后者。
- **手机版**：单页菜单式布局。
- **中英切换**：只有中英文两种；正文暂时只有英文，中文显示"准备中"。

### 地图交互（已定）

- **不能平移**：不能拖动或滚动整张图。点哪个点，哪个点就成为视觉中心。
- **镜头**：点开后按组放大，比如点 Photography，就以 Creative Work 为中心。
  - 放大倍数下限 1.35×、上限 2×，和窗口大小无关，保证字看得清。
  - 首页是全图，最小 0.8×。
- **优先级**：大小 > 全部显示。
  - 选中的点一定在画面内；放不下的点可以在画面外。
  - ✳ 能顺带带进画面就带，否则可以在画面外，左上角名字可以随时回首页。
- **动效**：点击后大约 2 秒内布局到位，之后完全静止，没有持续漂浮。单个点可以拖动，松手后回到稳定位置。
- **连线**：保持最初的折线风格；点有大有小、有轻有重、远近不均。
