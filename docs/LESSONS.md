# LESSONS：犯过的错 → 规则

> 每犯一次错就在这里加一条：**错误是什么、为什么会发生、以后的规则、用什么机制防止再犯**。
> 规则写进 `CLAUDE.md`；能自动检查的，加进 `scripts/check.mjs`（每次 build 都会先跑它）。
> 只追加，不删旧条目。编号永不复用。
